# Ashfall

Canonical id: `echothemecore:ashfall`

Ashfall is a survival interface theme with ash-gray panels, hazard orange rails, warning bands, and soot-dark transparent surfaces.

Token coverage:

- vanilla UI, loading, menu, HUD, item icon chrome
- ScreenCore universal kit
- Index, Lens, HoloMap, Terminal
- RenderCore overlays and reference textures

Cycle order: `30`
