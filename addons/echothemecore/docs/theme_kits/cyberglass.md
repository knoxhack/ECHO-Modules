# CyberGlass

Canonical id: `echothemecore:cyberglass`

CyberGlass is the default full replacement theme. It uses dark translucent glass, cyan hologram light, magenta accents, thin neon borders, and clean ECHO UI chrome.

Token coverage:

- vanilla UI, loading, menu, HUD, item icon chrome
- ScreenCore universal kit
- Index, Lens, HoloMap, Terminal
- RenderCore overlays and reference textures

Cycle order: `10`
