# CyberConsole

Canonical id: `echothemecore:cyberconsole`

Compatibility alias: `echothemecore:tech_console`

CyberConsole is a command-console theme with black-green panels, bright phosphor text color, amber operational accents, and sharp readable HUD chrome.

Token coverage:

- vanilla UI, loading, menu, HUD, item icon chrome
- ScreenCore universal kit
- Index, Lens, HoloMap, Terminal
- RenderCore overlays and reference textures

Cycle order: `20`
