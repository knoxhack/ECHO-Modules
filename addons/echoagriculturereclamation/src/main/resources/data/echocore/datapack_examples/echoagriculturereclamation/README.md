# Agriculture Reclamation Datapack Examples

Copy these files into a datapack under the same `data/<namespace>/echoagriculturereclamation/` paths and adjust ids or values as needed.

- `crops/example_clean_corn_tuning.json`: crop growth, yield, nutrient, and restoration tuning.
- `machines/example_hydroponics_greenhouse.json`: machine, hydroponics, greenhouse, and pollinator tuning.
