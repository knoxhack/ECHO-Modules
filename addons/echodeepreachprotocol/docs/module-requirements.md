# Deep Reach Module Requirements

## Required modules

Deep Reach requires the Foundation modules and the shared ECHO core modules that provide survival, content, world, and UI primitives.

### Foundation

- `echofoundationcore`
- `echomaterialcore`
- `echotoolcore`
- `echostationcore`
- `echoworldstarter`
- `echocommonloot`
- `echocreatureroles`

### ECHO core / platform

- `echonetcore`
- `echoadaptercore`
- `echocontentcore`
- `echoworldcore`
- `echobiomecore`
- `echostructurecore`

## Recommended / optional modules

- `echoindex` - in-game catalog for Deep Reach recipes and discoveries.
- `echotutorialcore` - onboarding for pressure-suit mechanics.
- `echoholomap` - 3D depth map and route visualization.
- `echolens` - field scanning of suits, fauna, and ruins.
- `echoterminal` - mission and habitat management screens.
- `echorecovery` - rescue and checkpoint systems for hardcore descents.
- `echoblockworks` - decorative hull, lighting, and structural blocks.
