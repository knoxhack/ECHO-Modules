# ECHO Arcana Division Protocol

Arcana Division is now a first-class official experience protocol. It owns the
fantasy and systems that were previously referenced through Ashfall profile
routes: magical research, rituals, familiars, curses, rifts, anomaly
containment, Arcana stations, Arcana loot, and Arcana world rules.

Arcana Division depends on ECHO Foundations for baseline survival. It does not
depend on Openlands or Ashfall.

## Owned Arcana Modules

| Module | Ownership |
| --- | --- |
| echoarcanacore | Arcana contracts, Aether Signal, providers |
| echoaetherworks | Aether machines and storage |
| echocursecore | Curse definitions and progression |
| echofamiliarcore | Familiar systems and companion contracts |
| echogrimoire | Magical knowledge and research archive |
| echoriftworlds | Rifts and pocket worlds |
| echoritualcore | Ritual altars, offerings, and ritual actions |
| echospellcore | Spells and cast patterns |

## Release Gate

Arcana Division reaches alpha only when Foundations load first, Arcana component
modules validate cleanly, Ashfall no longer owns Arcana routing, and no Arcana
module depends on Openlands or Ashfall.
